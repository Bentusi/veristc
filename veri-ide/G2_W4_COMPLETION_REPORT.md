## 技术决策

### D1: SCADE 风格布局

**理由**:
- ANSYS SCADE 是业界标准的嵌入式开发环境
- 三栏布局（项目树/画布/属性）符合工程师习惯
- 底部代码预览提供即时反馈
- 顶部工具栏集中常用操作

### D2: 属性面板集成

**理由**:
- 参数编辑是图形编辑器的核心需求
- 右侧面板不占用画布空间
- 实时编辑 + 实时预览提高开发效率
- 与 SCADE/SCADE One 保持一致

### D3: 接口管理独立

**理由**:
- 接口定义是程序契约，需要专门管理
- 左侧项目树提供快速访问
- 端口类型选择防止类型错误
- 与 ST 代码生成直接关联

## 使用示例

### 1. 启动编辑器

```bash
cd veri-ide/frontend/public
python3 -m http.server 8080
```

### 2. 加载示例

1. 打开 http://localhost:8080/graph-editor.html
2. 点击"加载示例"按钮
3. 查看 PID_CONTROL 示例

### 3. 编辑参数

1. 点击画布上的 pid1 块
2. 右侧显示属性面板
3. 修改 kp 值（如从 10 改为 20）
4. 查看底部 ST 代码更新

### 4. 管理接口

1. 点击左侧"接口端口"
2. 右侧显示接口编辑器
3. 添加新输入端口（如 "enable"）
4. 查看底部 ST 代码更新

### 5. 导出 JSON

1. 点击"导出 JSON"按钮
2. 保存为 `PID_CONTROL.fc.json`
3. 可导入后端进行编译

## 已知限制

1. **块类型有限**: 只支持 PID/LIMITER/RS/FBY
2. **单端口**: 每个块只有 1 个输入和 1 个输出端口
3. **无撤销/重做**: 刷新页面丢失编辑
4. **无自动布局**: 需手动调整位置
5. **无块库管理**: 自定义块需手动修改 JSON
